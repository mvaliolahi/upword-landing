آموزش زبان آلمانی (دورهٔ ۹۰ روزه) · درس ۷۹ از ۹۰

مجهول؛ گزارش‌های فنی و نامه‌های رسمی

🗓 ۳ آبان ۱۴۰۵ ⏱ ۱۰ دقیقه مطالعه ✍ تیم آپ‌ورد
⚡ پاسخ کوتاه

مجهولِ آلمانی: werden + Partizip — „Der Code wird geschrieben» (کد نوشته می‌شود)، „wurde deployt» (دیپلوی شد)، „ist veröffentlicht worden» (منتشر شده). مجهول، زبانِ داکیومنتِ فنی و نامه‌های اداری است: بدونِ «من»، فقط فرایند — از «Ich habe deployt» به «Das Deployment wurde durchgeführt».

مجهول در آلمانی، «زبانِ بی‌شخصِ حرفه‌ای» است: نامه‌های اداری، داکیومنتِ فنی، گزارش‌ها و اخبار — همه‌جا! و تو از درس‌های ۵۳ و ۶۱ قالبش را لمس کردی: „Ihr Antrag wird geprüft» — حالا کاملش را می‌سازی!

دو کاربردِ طلایی: ۱) رسمیتِ اداری (بدونِ من!)؛ ۲) تمرکز روی فرایند نه فاعل — در ریویو و داکیومنتِ فنی، مجهولِ مؤدبِ «این حل می‌شود» به‌جای «من حلش کردم»! این درس، آخرین ابزارِ بزرگِ گرامریِ زبانِ رسمیِ توست!

ساختِ مجهول؛ سه زمانِ پرکاربرد

زمان ساخت مثال
حال wird/werden + Partizip Der Bug wird gefixt. (باگ فیکس می‌شود)
گذشته wurde/wurden + Partizip Der Deploy wurde verschoben. (دیپلوی به تعویق افتاد)
کامل ist + Partizip + worden Die Version ist veröffentlicht worden. (نسخه منتشر شده است)
با مودال! muss/kann + … + werden Das muss heute noch werden? — Das muss noch gefixt werden! (باید هنوز فیکس شود)
Der Antrag wird geprüft. Die Unterlagen wurden überprüft. Der Bescheid ist verschickt worden.درخواست بررسی می‌شود. مدارک بازبینی شدند. جواب ارسال شده است. — سه زمانِ مجهول در سه جملهٔ اداریِ واقعی — دقیقاً نامه‌هایی که می‌گیری!

فاعلِ مجهول؛ «von» و «durch»

اگر فاعل را بخواهی بگویی: von + Dativ (شخص!) یا durch + Akkusativ (وسیله/سبب!): „Der Code wurde von Sarah reviewed« (کد توسطِ سارا ریویو شد) — „Der Fehler wurde durch einen Timing-Bug verursacht» (خطا به‌واسطهٔ یک باگِ تایمینگ ایجاد شد). در نامهٔ اداری و پست‌مورتم: von + شخص، durch + علت — دو حرفِ ردیابِ دقیق!

گفتگو: پست‌مورتم و داکیومنت — مجهولِ حرفه‌ای

Bericht: Am Freitag wurde die Version 2.5.0 deployed. Kurz danach wurde eine erhöhte Fehlerquote festgestellt.گزارش: جمعه نسخهٔ ۲.۵.۰ دیپلوی شد. مدتی بعد نرخِ خطایِ بالاتری مشاهده شد. — feststellen در مجهول: «مشاهده شد» — بی‌نفرِ رسمی!
Der Rollback wurde innerhalb von 20 Minuten durchgeführt. Die Ursache wurde durch die Log-Analyse identifiziert.رول‌بک در عرضِ ۲۰ دقیقه انجام شد. علت از طریقِ تحلیلِ لاگ شناسایی شد. — durchgeführt + identifiziert: دو فعلِ رسمیِ گزارشِ حرفه‌ای!
Es wurde beschlossen، den Check in die Pipeline zu integrieren. Damit kann das künftig vermieden werden.تصمیم گرفته شد که چک را در پایپ‌لاین یکپارچه کنیم. بدین‌ترتیب می‌توان از این در آینده اجتناب شد. — «Es wurde beschlossen» (تصمیم گرفته شد) + مجهولِ مودالی: می‌توان اجتناب شد — گزارشِ کاملِ بی‌جنگ!

اشتباه‌های رایجِ فارسی‌زبان‌ها در همین درس

این بخش را با یک قرارداد بخوان: هر ❌ یعنی «مغزِ فارسی‌زبانت این را می‌سازد و طبیعی است»، و هر ✅ یعنی «این همان چیزی است که گیرندهٔ آلمانی‌زبان می‌شنود». با هر جفت بلند تکرار کن تا شکلِ درست در گوشت نشست کند.

❌ Der Code ist geschrieben. (به‌عنوانِ مجهولِ حال!)❌ ist + Partizip حالتِ «کامل/نتیجه» است (Zustandspassiv!) — مجهولِ فرایندِ حال: wird geschrieben!
✅ Der Code wird jetzt geschrieben. / Der Code ist fertig geschrieben.✅ شکل درست را دو بار بلند بگو؛ حالا یک بار در یک جملهٔ خودت.
❌ Ich wurde geprüft von der Polizei. (ترتیب + معنا!)❌ در «من بررسی شدم» معنا غلط می‌شود! مفعولِ جمله باید «موضوع» باشد: Der Antrag wurde geprüft!
✅ Mein Antrag wurde geprüft. / Ich wurde gefragt. (من سوال شدم — درست!)✅ شکل درست را دو بار بلند بگو؛ حالا یک بار در یک جملهٔ خودت.
❌ Das muss werden gemacht.❌ مودال + Partizip + werden — ترتیبِ آخرِ جمله! «muss … gemacht werden»!
✅ Das muss noch gemacht werden. / Das kann nicht geändert werden.✅ شکل درست را دو بار بلند بگو؛ حالا یک بار در یک جملهٔ خودت.

تمرین‌های این درس — چهار قدم، بی‌عجله

تمرین: گزارش‌نویسِ حرفه‌ای شو!

  1. پنج جملهٔ «من»محور را مجهول کن: از Ich habe… به … wurde …!
  2. یک گزارشِ سه‌جمله‌ایِ پست‌مورتم بنویس — فقط مجهول!
  3. سه جملهٔ مجهولِ مودالی بساز: muss/kann/sollte … werden.
  4. یک پاراگرافِ داکیومنتِ فنی بنویس: «این ماژول برای X استفاده می‌شود…»

پاسخ تمرین‌ها — اول خودت جواب بده، بعد باز کن

پاسخ تمرین ۱
„Ich habe den Bug gefixt → Der Bug wurde gefixt.“ · „Wir haben deployt → Es wurde deployt / Das Deployment wurde durchgeführt.“ · „Ich habe die E-Mail geschickt → Die E-Mail wurde verschickt.“ — سه «من» به سه «فرایند» — زبانِ رسمی!
پاسخ تمرین ۲
„Am Montag wurde die neue Version deployed. Am Dienstag wurde ein Fehler in der Bezahl-API festgestellt. Der Fix wurde am Mittwoch ausgerollt.“ — سه جملهٔ مجهولِ گزارشِ واقعی!
پاسخ تمرین ۳
„Das muss bis Freitag gemacht werden.“ · „Das kann online beantragt werden.“ · „Das sollte im nächsten Sprint verbessert werden.“ — سه جملهٔ مودالیِ مجهولِ اداری-فنی!
پاسخ تمرین ۴
„Dieses Modul wird für die Nutzer-Authentifizierung verwendet. Die Tokens werden automatisch erneuert. Konfigurationen können über die env-Datei geändert werden.“ — سه جملهٔ داکیومنتِ واقعیِ READMEِ آلمانی! 😄

چالشِ امروز

🎯 امروز سه جملهٔ روزت را «مجهولِ حرفه‌ای» کن — در چت، در ذهن، در یادداشت: «Das wurde gemacht، das wird geprüft، das kann erledigt werden» — صدای رسمیِ آلمانی‌ات، از امروز!

نکات مکالمهٔ واقعی که کتاب‌ها کم می‌گویند

  • «Es wird …» — درِ هر جملهٔ بی‌فاعل! — Es wird geprüft، es wird davon abgesehen، es wird empfohlen… — «Es wird» آغازگرِ جمله‌هایِ رسمیِ بی‌شخص است؛ در نامه‌ها و خبرها همه‌جاست! جملهٔ ثبتِ رسمی: „Es wird darauf hingewiesen، dass…» (بدین‌وسیله توجه داده می‌شود که…)
🔑 جمع‌بندی این درس

مجهول: werden + Partizip — wird geprüft (حال)، wurde deployt (گذشته)، ist … worden (کامل)، muss … werden (مودال). فاعل: von + Dativ (شخص) / durch + Akk (علت). «Es wurde beschlossen»، «Das kann beantragt werden» — زبانِ رسمیِ بی‌شخصِ گزارش، داکیومنت و نامهٔ اداریِ تو!

پرسش‌های رایج

مجهولِ «sein» و «werden» چه فرقی دارند؟
werden-Passiv = فرایند (Der Laden wird geschlossen [فروشگاه بسته می‌شود — در حالِ بسته‌شدن!])؛ sein-Passiv = نتیجه/وضعیت (Der Laden ist geschlossen [بسته است!]). اولی داری اتفاق می‌افتد، دومی تمام شده! در نامه: „Das Formular ist unterschrieben worden» (امضا شده) vs. „Das Formular ist unterschrieben» (امضاشده است/بی‌نقص!)

آلمانی را همین امروز در گوشی‌ات تمرین کن

واژه‌های این درس را هر جا که دیدی با منوی «ذخیره در آپ‌ورد» به فلش‌کارت‌هایت اضافه کن؛ الگوریتم مرور فاصله‌دار سرِ موعد یادآوری‌شان می‌کند، تلفظ‌شان را با صدای آلمانی می‌شنوی و در مکالمهٔ هوش مصنوعی همان‌جا که لازم است استفاده‌شان می‌کنی.

# RU Course Authoring Spec — v117 (برای تألیف ru_course_data_*.py)

## هدف
فایل دیتای درس‌های دورهٔ ۹۰ روزهٔ زبان روسی آپ‌ورد — فارسی برای فارسی‌زبان‌ها.
سبک = دقیقاً مثل دورهٔ آلمانی موجود در همین ریپو (فایل `scripts/de_course_data_01.py` را بخوان تا لحن و عمق را ببینی).

## قالب فایل
```python
# -*- coding: utf-8 -*-
"""دورهٔ ۹۰ روزهٔ روسی — فایل دادهٔ N (درس‌های A تا B: فاز X)."""

LESSONS = [
    {
        'slug': 'russian-...',          # از بریف؛ دست‌کاری نکن
        'title': '...',                  # از بریف؛ روان و با «؛»
        'desc': '...',                   # توضیح متا ~140-160 کاراکتر
        'keywords': 'کلمات کلیدی, جدا, با کاما',
        'answer': '...',                 # «پاسخ کوتاه» AEO: 40-60 واژه مستقیم
        'intro': ['پاراگراف ۱ (۳-۵ جمله)', 'پاراگراف ۲ (۳-۵ جمله)'],
        'sections': [ ... ],             # ۷-۸ بخش طبق ساختار پایین
        'takeaway': '...',               # جمع‌بندی ۲-۳ جمله
        'faq': [('پرسش ۱؟', 'پاسخ ۱ (۲-۴ جمله)'), ('پرسش ۲؟', 'پاسخ ۲')],
    },
]
```

## ساختار sections (به همین ترتیب، ۷-۸ بخش)
1. هستهٔ آموزشی بخش ۱: `{'h2': '...', 'blocks': [('p','...'), ('table', [...],[[...]]), ('ex','русский','فارسی')]}`
2. هستهٔ آموزشی بخش ۲ (جدول یا مثال‌های بیشتر)
3. `'گفتگو: ...'` — ۴-۵ مثال ex به شکل مکالمهٔ واقعی (با — برای نقش‌ها)
4. `'گرامرِ عمیق‌تر: ...'` — عمق گرامری + چرا (مفید برای فارسی‌زبان)
5. `'اشتباه‌های رایجِ فارسی‌زبان‌ها در همین درس'` — ۳-۴ جفت ❌/✅ با ex
6. `'تمرین‌های این درس — چهار قدم، بی‌عجله'` — `('ol',[...۴ تمرین...])` + `('faq', [('پاسخ تمرین ۱','...'), ...×۴])`
7. `'چالشِ امروز'` — یک `('quote', '🎯 ...')`
8. `'نکات مکالمهٔ واقعی که کتاب‌ها کم می‌گویند'` — `('ul', [...۳ مورد با **بولد**...])`

## انواع block مجاز
- `('p', 'متن')` — پراگراف با **بولد** و `کد`
- `('ex', 'русский текст', 'ترجمهٔ فارسی')` — ⚠️ فقط ۲ فیلد! ex3 و آوانگاری ممنوع
- `('table', ['ستون۱','ستون۲'], [['ردیف'], ['ردیف']])`
- `('ul', [...])` و `('ol', [...])`
- `('quote', '...')` — فقط برای چالش
- `('faq', [('پاسخ تمرین ۱', '...'), ...])` — فقط داخل بخش تمرین
- ممنوع: 'ex3', 'callout' (فقط lib می‌سازد)

## قوانین زبانی (خیلی مهم — QA خودکار گیر می‌دهد)
1. **فیلد اول ex فقط روسیِ سالم**: تمام حروف باید سیریلیک باشند. هیچ حرف فارسی یا لاتین داخل واژهٔ روسی ممنوع.
2. **متن فارسی فقط حروف فارسی**: اگر کلمهٔ روسی داخل متن فارسی می‌آیدی (مثل РВП یا МФЦ)، جدا و کاملاً سیریلیک بنویس — هرگز ترکیب دو خط در یک واژه ممنوع.
3. **بدون آوانگاری**: هرگز «پری‌وِت» ننویس؛ تلفظ را TTS اپ می‌گوید. توضیح تلفظ فقط داخل متن فارسی با حروف فارسی مجاز است (مثل: حرف «в» در روسی مثل «و» است).
4. روسی را با دقت صرف کن: جنس، شکل حالت، شخص فعل، تکیه (میتوانی ´ بگذاری روی واژه‌های حساس مثل замо́к).
5. لحن: «تو» (خطاب به دانشجو)، صمیمی اما دقیق، با مثال‌های زندگیِ واقعیِ ایران-روسیه (دانشجو، خوابگاه، اداره، کار).

## نکات کیفیت
- هر درس ۹۵۰-۱۳۰۰ واژهٔ فارسی + ۱۲-۲۰ مثال روسی داشته باشد.
- جدول‌ها واقعی و قابل‌استفاده باشند (واژه‌هایی که همان هفته لازم می‌شوند).
- تمرین‌ها «دهان‌محور» باشند (بلندگفتن، ضبط، نقش‌بازی) نه امتحانی.
- چالش هر درس: یک کارِ ۵ دقیقه‌ایِ همان روز.
- FAQ انتهای درس: ۲ پرسشِ واقعیِ یک فارسی‌زبانِ در وضعیت یادگیریِ همان درس (مثل «آیا ...؟»)، نه پرسش امتحانی.
- هر درس به درس‌های قبل/بعد ارجاع بدهد با شماره (مثل «درس ۴۶») وقتی منطقی است.
